# Getting started

1. Clone the repo and work from its root.
2. When a user names a war and pastes a script, follow `skills/historical-animation/SKILL.md`.
3. Read `docs/house-rules.md` and `docs/placement.md` before drawing.
4. Render with `docs/renderer.md`. Silence is already the default. Subtitles come from the script.

Python 3.10, Pillow, FFmpeg (`libx264`, `aac`), and `rsvg-convert` are the renderer dependencies. Fonts are Liberation Sans or DejaVu, from the system.
