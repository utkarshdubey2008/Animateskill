# Skill anatomy

```
skills/<name>/SKILL.md
```

```markdown
---
name: <name>
description: <What it does. Use when [the user's words].>
---

# Title

## Overview
## When to use
## Steps
## Checks
```

Put a long sample in `examples.md`. Put a shared rule in `docs/` and link it. The description is what makes an agent pick the skill up, so name the objects the user will say: map, portrait, army, subtitle, script, battle.
